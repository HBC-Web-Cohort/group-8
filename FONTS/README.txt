BAHIJ TITR FONT
===============
The website is already set up to use the "Bahij Titr" font for all four
languages (English, Persian, Pashto, Arabic).

To activate it, copy your font files into THIS folder and name them exactly:

    BahijTitr-Regular.woff2   (or .woff / .ttf)
    BahijTitr-Bold.woff2      (or .woff / .ttf)

You only need one format per weight. .woff2 is the smallest, but .ttf works too.
If a file is missing, the browser safely uses the next font (Segoe UI, Tahoma,
Noto Naskh Arabic ...) so the site never breaks.

Check the font licence of Bahij Titr before publishing the website online.
